# 解压触发器（Triggers.txt）

在解压成功后自动执行自定义动作：可以先弹一个文本输入框，再把输入的内容连同路径传给一个外部命令行程序。

实现位置：`CPP/7zip/UI/GUI/ExtractGUI.cpp`（`RunExtractTriggers()`），挂在该文件原有的
"解压后打开目标文件夹"（`OpnTrgFold`）逻辑之前。

## 何时触发

解压过程成功结束（`ExtractGUI()` 返回 S_OK 且没有跳过的文件）之后，逐条匹配规则。

- 触发：7zFM 工具栏 Extract、Extract Here / Extract To、资源管理器右键解压、直接运行 7zG.exe 解压。
  7zFM 的解压实际由 7zG.exe 子进程完成，所以弹窗和外部程序都由 7zG 进程发起。
- 不触发：Test（测试压缩包）、校验和计算、压缩、解压失败或用户中途取消。

## 配置文件位置

按顺序查找，用第一个存在的文件；每次解压后重新读取，改完不需要重启：

1. `<7zG.exe / 7zFM.exe 所在目录>\Triggers.txt`
2. `%APPDATA%\7-Zip-Zstandard\Triggers.txt`

两个位置都不存在时，功能完全静默（无任何提示）。

编码：按 UTF-8（有无 BOM 都行）→ UTF-16 LE（需带 BOM，记事本存这种会自动带）→ 记事本"ANSI"（系统代码页）
的顺序自动尝试。注释行以 `#` 或 `;` 开头。建议直接用 UTF-8。

## 格式

每条规则以 `trigger` 开始，`end` 结束（`end` 可省略，下一个 `trigger` 会自动结束上一条）。
`[trigger]` / `[end]` 写法同样接受。每行 `key = value`，键名大小写无关，键和值两侧的空格会被去掉。

| 键 | 必填 | 说明 |
|----|------|------|
| `dest` | 是 | 要匹配的解压目标文件夹（通配符，见下） |
| `cmd` | 是 | 要执行的命令行模板（占位符，见下） |
| `ask` | 否 | 输入框上方的提示文字。留空表示不弹窗，直接执行 |
| `title` | 否 | 弹窗标题，默认 `7-Zip` |
| `default` | 否 | 输入框的预填文本 |

规则按文件中的顺序执行，第一条匹配的规则先跑。

## dest 通配符

对解压目标目录的绝对路径做匹配，大小写无关，`\` 与 `/` 等价，末尾多余的 `\` 会被忽略。

- `?` 匹配一个字符（不含路径分隔符）
- `*` 匹配一段内容，不跨越路径分隔符
- `**` 匹配任意内容，可跨越路径分隔符
- 不含通配符时，只匹配该目录本身

例子：

| 规则 | 匹配 |
|------|------|
| `dest = D:\Games` | 只有正好解压到 `D:\Games` 时 |
| `dest = D:\Games\**` | `D:\Games` 本身，以及它下面任意深度 |
| `dest = D:\Games\*` | `D:\Games` 的直接子目录，或 `D:\Games` 本身 |
| `dest = **\Patch\v?` | 任何盘、任何父目录下的 `\Patch\v1` `\Patch\v2` … |

## cmd 占位符

| 占位符 | 含义 |
|--------|------|
| `%text%` | 弹窗里输入的文本；不弹窗时为 `default` 的值，两者都没有则为空 |
| `%dest%` / `%path%` | 解压目标目录，绝对路径，末尾无 `\` |
| `%arc%` | 压缩包完整路径 |
| `%aname%` | 压缩包文件名，不含目录和扩展名 |
| `%%` | 一个字面 `%` |

未识别的 `%xxx%` 原样保留。**需要引号的地方自己写**：路径可能含空格，所以模板里给 `%text%`、`%dest%`
以及程序名本身加引号，例如 `"%text%"`。

## 执行方式

整条命令行交给 `CreateProcessW`，工作目录设为 `%dest%`。控制台窗口可见，7-Zip 会等它退出：

- 返回码非 0 → 弹错误框显示返回码，并停止后面的规则
- 无法启动（程序不存在等）→ 弹错误框显示系统和命令信息，并停止后面的规则
- 弹窗里点 Cancel → 跳过本条并停止后面的规则，解压结果不受影响

错误框使用独立的 MessageBox，不受 `-y`（7zFM 调用 7zG 时总带 `-y`，普通提示会被静音）影响，一定会显示。

## 示例

```
# 解压到 D:\Games 下任何一个子目录时，先问名字，再调用改名工具
trigger
  dest = D:\Games\**
  title = 给游戏起名
  ask = 请输入名称：
  default =
  cmd = "C:\Tools\renamer.exe" --name "%text%" --dir "%dest%" --src "%arc%"
end

# 解压到补丁目录时不问任何东西，直接跑脚本
trigger
  dest = *\Patch
  cmd = "D:\Scripts\post.cmd" "%dest%" "%aname%"
end
```
